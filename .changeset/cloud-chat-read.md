Read your cloud chats from the terminal: `dexto chat list` lists and searches them, `dexto chat get` reads one's messages, and `dexto chat models` lists the models a chat can use. `dexto chat list --local` lists this machine's chats, which `dexto chat list` showed before. `dexto chat follow` and `dexto chat outputs` now run from `dexto` itself.
