`dexto chat delete` deletes one of your own cloud chats, the same way `dexto_chat_delete` does, and takes `--json`, `--profile`, `--yes` and `--dry-run` like the other cloud chat commands. A chat stored on this machine is deleted with `--local`, which also deletes its synced copy. Both ask first; pass `--yes` when not at a terminal.
